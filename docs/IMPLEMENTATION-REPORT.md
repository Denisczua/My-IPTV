Проверки настоящих потоков не проводились. Доступность в Чехии и воспроизведение
на Samsung/OTTPlayer пока не подтверждены. Языки определены по открытым метаданным,
не по прослушиванию. Отсутствие исключений XXX не является покадровой проверкой контента.

Подготовлены фильтр языка, фильтр специализации, единый механизм категорий,
Windows-агент проверки видео с FFmpeg/FFprobe, журнал результатов, возобновляемые
партии, ограничение нагрузки, защита прежнего результата и отдельный workflow.
Скрипты используют стандартную библиотеку Python и бесплатные внешние инструменты.

Созданные компоненты:

- `scripts/filter_ru_ua.py`, `scripts/check_ru_ua.py`;
- `scripts/ru_ua_categories.py`, `scripts/ru_ua_content.py`;
- `scripts/run-cz-check.ps1`, `tests/test_ru_ua.py`;
- `.github/workflows/ru-ua.yml`, `.github/actionlint.yaml`, `.gitignore`;
- `playlist-ru-ua-testing.m3u`;
- `data/`: языковые и тематические снимки IPTV-org, ручные настройки,
  диагностическая база, список ручной проверки, последний отчёт и история;
- `docs/RU-UA-WINDOWS.md`, этот отчёт; дополнен `README.md`.

В архивной базе 868 записей: кроме 708 текущих кандидатов сохранены 160 записей,
исключённых при переходе от предварительной классификации по каналу к точным
метаданным версии потока. Они не включены в плейлист и не потеряны.

Проверено: 25 автоматических тестов на искусственных данных, actionlint 1.7.7
для обоих workflow, синтаксис PowerShell, структура всех 733 выходных записей,
соответствие их URL/атрибутов исходнику, отсутствие фиктивных результатов проверок.
FFmpeg/FFprobe и реальное воспроизведение не запускались в этой среде.

`playlist.m3u`, `channels.json` и `scripts/update_playlist.py` не изменены.
SHA-256 исходного плейлиста:
`66c72e5b15be9c4ec954aa51ca42db571a066413f1373103efed5beaeF87faaf`
(регистр шестнадцатеричных символов значения не меняет).
В существующий workflow добавлен только `git pull --rebase` перед push для
сосуществования автоматических коммитов. Его расписание и алгоритм сохранены.

Позднее пользователю нужно отправить подготовленную ветку в GitHub и включить
изменения в main; установить на чешском Windows-компьютере Python, Git и FFmpeg
с FFprobe; зарегистрировать runner `iptv-cz`; включить `CZ_CHECKS_ENABLED=true`;
выполнить первый запуск и дождаться повторных проверок. OLED-список заполняется
после визуального просмотра, а не по логотипу M3U. Подробные команды, форматы
настроек и ограничения приведены в [инструкции](RU-UA-WINDOWS.md).

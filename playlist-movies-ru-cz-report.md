## Автообновление

GitHub Actions запускает проверку по расписанию на настроенном Windows runner с меткой `iptv-cz`.
Для запуска нужны переменная репозитория `CZ_CHECKS_ENABLED=true`, Python, FFmpeg и FFprobe в PATH
и прямое подключение в Чехии. Расписание GitHub работает после попадания workflow в ветку по умолчанию.
Workflow читает свежий `playlist.m3u` из ветки по умолчанию и публикует результаты в `codex/movies-ru-cz`.
Адрес для автообновления в OTTPlayer остаётся тем же при последующих обновлениях этой ветки.

В `data/movies-sources.json` в поле `review` указываются доказательства бесплатной законной
публикации конкретного URL, фильмовой сетки, отсутствия тематики 18+ и языка аудиодорожки.
Укажите проверенный язык (`ru` или `uk`), измеренные размеры кадра в `size` и, при необходимости,
конкретный вариант HLS в `playback_url`. При замене исходного или проверенного URL потребуются две новые проверки.
При равной стабильности версий выбирается Full HD. Последние две успешные проверки должны укладываться
в три дня и начинаться с интервалом от десяти минут. При отсутствии прошедших потоков M3U отсутствует.
